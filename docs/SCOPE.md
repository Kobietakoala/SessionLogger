# Scope – Session Logger

## Must-have 
- [ ] Students: create/read/update/archive/delete
- [ ] Sessions: create/read/update/delete
- [ ] Filtr sesji po uczniu
- [ ] Walidacja danych wejściowych
- [ ] Docker Compose local run
- [ ] Sortowanie, paginacja / limit
- [ ] Przechowywanie plików
- [ ] prosty auth

- [ ] Integracje kalendarza buki(za pomocą ss'a)/google
- [ ] Generowanie testu sprawdzającego czas liczenia / wiedzę z poprzednich zajęć
- [ ] Możliwość przesyłania ankiety po zakonczeniu zajęć
- [ ] Ankiety: create/read/update/archive/delete

- [ ] Panel admin / logi audytowe
